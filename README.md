# NYXARA AI

NYXARA AI is an independent research project focused on building an AI system from first principles. The long-term goal is to develop a foundation model trained from random initialization, with a strong emphasis on understanding, documentation, and iterative experimentation.

This repository is structured as a learning and research roadmap: it starts with fundamentals, moves through mathematics and computer science, and gradually progresses toward machine learning, deep learning, and foundation-model research.

## Project vision

The core aim is to build NYXARA as a fully independent AI system with:

- a custom model architecture
- a tokenizer
- a training data pipeline
- randomly initialized model weights
- a training and evaluation system

The project follows a research-first philosophy inspired by adaptive intelligence and systems built from fundamentals rather than pretrained shortcuts.

## Research roadmap

- NYXARA 0.1: Experimental 1M-parameter model
- NYXARA 0.2: Improved language generation
- NYXARA 0.5: Knowledge and reasoning experiments
- NYXARA 1.0: General-purpose AI assistant research
- NYXARA 2.0: Multilingual intelligence research

## Development principles

1. Build from fundamentals.
2. Do not use pretrained model weights.
3. Document every experiment.
4. Use legally permitted training data.
5. Evaluate before claiming improvements.
6. Develop consistently every day.

## Learning philosophy

This project follows a step-by-step educational system:

- Programming fundamentals
- Mathematical foundations
- Computer science
- Software engineering
- Machine learning
- Deep learning
- Foundation models
- NYXARA AI research and development

The repository emphasizes understanding intuition before formulas, explaining algorithms before code, and documenting concepts clearly.
