## Concepts

### Variable
A named reference to a value used by a program.

### Assignment
The = operator assigns a value to a variable.

### Data types
- int: whole numbers
- float: decimal numbers
- str: text
- bool: True or False

### Reassignment
A variable can receive a new value.

### Arithmetic operators
+ Addition
- Subtraction
* Multiplication
/ Division
