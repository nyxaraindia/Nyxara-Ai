# NYXARA AI — Day 1

## Topic
Understanding Computers and Logic

## Learning objectives
- Understand what a computer does.
- Understand instructions and programs.
- Learn input, processing and output.
- Understand basic logical reasoning.

## Concepts covered

### 1. Computer
A computer is a machine that follows instructions.

### 2. Program
A program is a collection of instructions.

### 3. Input
Information given to a computer.

### 4. Processing
Operations performed on the input.

### 5. Output
The result produced by the computer.

### 6. Logic
Using rules and information to reach a conclusion.

## Mathematical example
A customer has ₹100 and an item costs ₹120.

100 < 120

The customer does not have enough money.

## Practical exercise
Available money: ₹500
Product price: ₹350

Questions:
1. Identify the input.
2. Explain the processing.
3. Identify the output.

## Student challenge: Pass or Fail algorithm

Student's independent algorithm:

START
INPUT mark scored by student
IF mark < 40
    DISPLAY "FAIL"
OTHERWISE
    DISPLAY "PASS"
STOP

### Evaluation
- Correct input identification.
- Correct comparison.
- Correct handling of both outcomes.
- Algorithm accepted.

## New concept: Dry run
A dry run manually tests an algorithm with sample inputs.

### Test cases
| Marks | Condition marks < 40 | Result |
|---:|---|---|
| 25 | TRUE | FAIL |
| 39 | TRUE | FAIL |
| 40 | FALSE | PASS |
| 65 | FALSE | PASS |
| 100 | FALSE | PASS |

### Boundary value
40 is the boundary between FAIL and PASS.
