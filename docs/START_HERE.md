# NYXARA AI - Start Here

## Learning rule
Start from absolute zero. Explain every concept simply (ELI5).

## Learning order
1. Programming fundamentals
2. Mathematical foundations
3. Computer science
4. Software engineering
5. Machine learning
6. Deep learning
7. Foundation models
8. NYXARA AI research and development

## Teaching approach
- Explain intuition before formulas.
- Explain algorithms before Python code.
- Explain every line of code.
- Include mathematics in programming lessons.
- Give exercises and test understanding.
- Progress according to demonstrated understanding.

## Long-term goal
Build an independent AI model from random initialization.

- NYXARA 0.1: approximately 1M parameters
- NYXARA 0.2: intermediate improvement
- NYXARA 0.5: intermediate scaling
- NYXARA 1.0: approximately 1B parameters

Research direction: Adaptive Intelligence.
